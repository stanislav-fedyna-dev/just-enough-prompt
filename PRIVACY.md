# Privacy policy

_Last updated: 2026-11-24_

**just-enough-prompt** is a set of plain-text instructions (a skill) that your AI agent reads. It contains no code, no tracking, and no servers.

- **The author collects nothing.** The skill does not send, store or log any data anywhere.
- **Your agent does the work.** The prompt you ask it to improve is processed by your agent (for example Claude) under the privacy terms of that agent, not this project.

Questions: open an issue at https://github.com/stanislav-fedyna-dev/just-enough-prompt/issues
