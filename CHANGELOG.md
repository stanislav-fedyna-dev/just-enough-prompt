# Changelog

## 1.0.0 — 2026-11-24

- First public release: English, tool-agnostic version of the original Ukrainian `prompt-improver` skill.
- New gotchas: never invent facts (use placeholders), keep the prompt's language, no "think step by step" for reasoning models, explain the why instead of shouting.
- Anti-pattern #9 "Invented specifics"; examples rewritten to use placeholders.
- Quality and trigger evals; spec validator, CI, release workflow.
