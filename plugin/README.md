# just-enough-prompt

An agent skill that improves a prompt by adding only the prompt-engineering practices it is missing, then shows a short table of what was added, what was skipped, and why.

- Skill: `skills/just-enough-prompt/SKILL.md`
- Docs, install options and examples: https://github.com/stanislav-fedyna-dev/just-enough-prompt

The practice catalog draws on the Prompt Engineering Guide by DAIR.AI (MIT).
